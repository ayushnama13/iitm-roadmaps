# CS roadmap

Computer Science & Engineering (source: CourseDetails_CS.pdf, 296 entries).

## How to use a course file

1. Watch the **🎓 Main course** playlist in order, following the **Study plan** table (it links each week to the exact lecture videos).
2. If a lecturer doesn't work for you, switch to one of the **🎥 Other full lecture series**; use **⚡ Short videos** for intuition before or after a hard topic.
3. Read the book chapters and do the **Practice** project. Watching alone is not learning.

**About the links:** every YouTube playlist was opened on 2026-10-22; its title, video count and lecture list are copied from YouTube, not typed by hand. Official channels (NPTEL, IIT Madras, MIT OCW, Stanford Online, CMU, Harvard and others) were preferred; uploads by other people are marked *re-upload*. In the Books section, ✅ means the link was checked in a web search; other book/website links were not re-checked, so confirm they are still online.

Tier A = core, do it. Tier B = recommended elective. Tier C = advanced, only after its prerequisites.

## Not doable (or not worth doing) as self-study

| Course(s) | Why |
|---|---|
| INSA*, INS* (Analog devices, Semiconductor devices ...) | Interdisciplinary courses with empty syllabus text in the PDF; nothing to plan from. |
| RC*, RCCS*, Research credits / Comprehensive exam / Seminar 2 | Not courses; they record research work. |
| CS4900, CS4910, CS5705, CS5715, CS5980/5990/6000, CS5931/5932, CS5998, CS6008/6019/6119, ID5490-93, CS6900 | Projects and thesis credits, assigned by a supervisor. |
| CS3660, CS3666 Industrial Training | Needs an internship. |
| CS4999 Seminar, CS7999, CS6190, CS7xxx Topics/Recent topics courses | Rotating research-paper seminars; no fixed syllabus. |
| CS6853 GIAN, CS8852 | One-off visiting-faculty courses. |
| NUS* courses | Exchange-programme equivalents of the same subjects; use the main CS course instead. |
| CS6840, CS6845, CS6850, CS6240, CS6122, CS6101, CS6170, CS6841, CS6025, CS6535, CS6525, CS6780 | Research-level theory (complexity, pseudorandomness, approximation, parameterised algorithms). Do CS2800 + CS2200 + CS1202 well first; then pick one. |
| CS6760W, CS6230W, CS6330, CS6620W, CS6640 | VLSI/testing/advanced architecture; only if you plan hardware work. |
| Remaining PG electives (wireless, IoT, quantum, blockchain, ontologies ...) | Doable later if you want that niche; no roadmap written now. |
